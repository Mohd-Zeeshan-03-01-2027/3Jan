# Wedding Invitation

Host on GitHub Pages:
1. Create a new repo and upload everything in this folder (index.html at the top level).
2. Settings > Pages > Deploy from a branch > main > / (root) > Save.
3. Open https://USERNAME.github.io/REPO/ on your phone.

Edit names/dates in index.html and script.js (search for 2027). Replace assets/music.mp3 to change the song.
